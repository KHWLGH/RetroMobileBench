SciMark 2.0 (C) — https://math.nist.gov/scimark2/
Authors: Roldan Pozo and Bruce Miller, National Institute of Standards and Technology.
NIST Public Domain numerical benchmark (original archive scimark2c.zip).
Local changes add allocation failure checks and thread-safe static constant initialization in Random.c / MonteCarlo.c without altering core math; times single-thread and multi-thread kernels separately and reports composite MFLOPS.

STREAM — https://www.cs.virginia.edu/stream/
Reference mirror: https://github.com/jeffhammond/STREAM
Pinned commit: 6703f7504a38a8da96b353cadafa64d3c2d7a2d3
Copyright 1991-2003: John D. McCalpin.
Based on a variant of the STREAM benchmark code.
Uses pthreads and a shared fixed 24 MiB working set (3 × 8 MiB) partitioned along cache-line boundaries with no overlap; computes bandwidth (MB/s) from completed elements × 24 bytes / elapsed time. See the appended LICENSE.txt for the full license statement.
