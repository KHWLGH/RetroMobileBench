# 09 实施门槛与待验证项

2026-11-14 更新。范围冻结为 [12 固定套件计划](12-test-suite-plan.md)，代码与实际检查记录见 [13](13-suite-implementation.md)。本页替代旧的六项离屏、lite/full、总分与“对照历史分数±10%”路线。

| 阶段 | 实施范围 | 验证门槛 |
|---|---|---|
| M1 | r10e/API8新库、固定素材、系统解码原型、LGPL交付 | 构建与ELF/无NEON检查；真实系统输出；API8/9加载与素材/许可证据 |
| M2 | 固定14阶段、8阶段自动三轮、1+N、逐轮会话检查点、保存异常、温升统计 | 单核省重复、8工作线程完成、旧记录可读、保存失败可导出、高温不拦截 |
| M3 | 加密、六图、四H.264+三旧格式视频，系统进程隔离 | 已知向量/像素/帧正确性；软件、系统、播放分别有状态；超时/缺失不混淆 |
| M4 | 四场景模式+Fill、一键UI、完整离线资源 | 真实窗口提交，1080p离屏；取消/中断/崩溃后保留结果；独立准备超时 |
| M5 | 真机回归与分发 | ARM旧系统、API16厂商硬解、8核、无NEON、x86、API29属性；安装/解包/运行峰值与时长 |

代码接入、构建检查、模拟器验证和真机验收分别记录；不能因为模拟器通过就把M1/M5全部标为完成。发布仍要求匹配APK的完整对应源码ZIP、构建说明与许可。

重点风险：

- 老设备新库加载/厂商驱动行为；静态符号与指令检查只能排除部分风险。
- 厂商系统解码器的输出布局、卡死/崩溃和硬件属性可观测性；独立进程与可追溯状态是基本保护。
- 完整GPU资源的APK、安装空间、暂存与运行内存成本；不得以默认缺场景的包替代完整产品。
- 8核热插拔/调度能力；工作线程数与物理并行分开解释。

本轮不扩展网络、编码、音频、4K、新视频格式、ES3、续航压力或完整缓存层级扫描。Zstd/完整STREAM四内核/ALU/Driver/Blending仅保留必要诊断与历史解释；恢复Triad和Fill，不增加产品选择菜单。
