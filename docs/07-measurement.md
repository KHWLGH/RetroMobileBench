# 07 测量方法与可比边界

2026-11-14 更新。CoreMark、SciMark、zlib、加密、图片、内存、文件存储、SQLite各三轮，视频及每个GPU模式各一次，固定顺序串行执行；阶段间固定休息1秒，最后不空等。不提供冷却门槛、温度设置或未经校准的综合分。

三轮连续运行同一阶段，轮间固定1秒，无末尾等待；保留所有原始样本，只有全部完成且协议/构建/参数一致才生成中位数，缺项不填零。图片按素材ID、压缩文件与参考像素哈希、尺寸、格式和库匹配，分别计算六图的MPix/s和ms/张中位数。每轮完成即写会话active_report检查点；中断恢复保留已完成轮次，不合成正常成绩。

## CPU与计时

原生使用CLOCK_MONOTONIC墙钟；预热、已知向量和输出验证尽量放计时外，具体窗口和纳入工作写入协议。CoreMark正式阶段至少10秒，保留两套种子输出。zlib/加密为单线程+N，单核省掉重复并行。N参考实际present/CPU目录及在线/运行时，configured只在缺实际拓扑时后备，possible不盲信；当前资源容量64，超限不静默截断。

系统自行处理热插拔、调度和调频；不要求root，不绑核、不修改governor。前后在线数/频率为快照，不能证明全程有N个物理核同时运行；成功创建8个pthread与8核真机并行仍需分别验证。

## 正确性与媒体

加密固定MbedTLS版本，验证AES/GCM/SHA已知向量、错误标签拒绝和往返数据；GCM解密包含认证。图片复用输出缓冲区，计时含真实RGBA8像素解码、不含磁盘；JPEG使用固定标量accurate DCT/fancy upsampling参考，PNG保留非预乘RGBA，两者逐字节校验。

软件视频真实生成YUV420帧，校验首帧完整哈希；吞吐包括固定缓存文件读取/解封装，结果记录线程请求与实际线程类型。系统视频按确定规则选择命名解码器，最多一个后备，配置并实际送入/取出数据；尺寸、PTS、EOS和可读线性输出抽样检查独立记录。不可读颜色布局标为画质抽查不可获得。

播放按PTS节奏提交Surface，记录已解码/提交数量；输出fps不代表精确显示fps，系统属性或厂商名称不构成独立硬件证明。API8–15 MediaPlayer播放成功只能证明系统播放路径成功，硬解类型未确认。失败校验不保留正常吞吐量，超时与不支持分别报告。

## 内存与存储

8MiB复制/填充和4MiB依赖链不是完整缓存层级扫描，也不保证纯DRAM负载。复制按读+写字节计算。存储默认32MiB、最低4MiB、16MiB空间预留，O_SYNC写，优先O_DIRECT读；不支持时明确标记cached，不假装已经驱逐页缓存。文件系统、缓存模式、文件大小不同不直接混算。

Triad并入同一内存阶段，复用STREAM `a=b+3*c`，三个double数组各8MiB，总24MiB；单线程与N线程使用相同总工作集，按64字节边界划分互不重叠区间。先释放复制/延迟工作区再分配Triad。每项至少1.5秒，统一起点/截止，按所有线程实际完成元素数×24字节/总墙钟秒数计算十进制MB/s；全量验证a=11、b=2、c=3。初始化、预热和校验不计时，取消/线程创建失败须释放并回收全部已创建线程。固定小工作集可能受缓存影响，标注为STREAM变体，不声称标准STREAM或纯DRAM带宽。

## GPU

固定Egypt离屏、屏上、T-Rex离屏、屏上、Fill离屏，配置时长113+113+56+56+60=398秒，加载/准备另计。离屏1080p用于同协议比较；屏上使用实际窗口EGLSurface并交换缓冲区，受自身分辨率、刷新率和VSync影响，两类FPS独立展示。记录渲染尺寸、显示刷新率、交换间隔请求与GPU身份；这些不证明每个提交帧都已在屏上显示。

Fill报告MTexels/s，不把其辅助帧数/FPS当成主成绩，也不等同显存峰值带宽。保留完整60秒以包含上游自适应负载调整，短诊断不能替代正式结果。

保留上游同步行为，不为追求分数随意增删glFinish；移植代码来自后续开源GFXBench，不与历史官方成绩直接等价。模拟器的GPU由宿主转译，只用于流程验证。完整场景当前要求至少192MiB可用内存，需真机测峰值后审查。

## 温度与运行条件

约2秒采样一次电池广播，记录整次和各阶段起止、采样最大值、结束减开始的温升、充电状态、来源和时间戳。缺失/异常值不填0；温度不阻止、暂停或跳过测试。不称CPU/GPU结温，不仅凭温升判定降频；系统自身保护照常生效。低电量<30%且未充电、真实内存/空间不足仍明确说明。

会话/分项保存版本、构建、素材哈希、实际线程、设备及状态原因。缺项不算零；旧协议保留解释，参数/构建不同不合并。取消立即反馈并在安全边界结束，整次报告记录请求时间与实际停止延迟；切后台/锁屏/Surface丢失按中断处理，保留前面成绩。
